# 🤖 Mode Chatbot

A simple Generative AI chatbot built with Python, LangChain, Gemini, and Streamlit.

The chatbot provides different response modes, allowing the user to choose how the AI should respond.

## ✨ Features

- 💢 Angry Mode
- 😂 Funny Mode
- ✍️ Poetic Mode
- 👨‍🏫 Teacher Mode
- 💬 Interactive chat interface
- 🌐 Streamlit web interface

## 🛠️ Technologies Used

- Python
- LangChain
- Google Gemini
- Streamlit
- python-dotenv

## 🚀 How It Works

The user selects a mode and enters a message.

The selected mode changes the instructions given to the Gemini model, which then generates a response according to that personality/style.

This project was built to learn and practice the fundamentals of Generative AI, LangChain, prompt-based behavior, and deploying an AI application using Streamlit.
